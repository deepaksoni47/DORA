This folder contains the Flutter mobile application for DORA.

## Planned Responsibility

- mobile search interface
- responsive result browsing
- filter support for content type, source, and year
- future saved searches and bookmarks

## Current Flutter Structure

```text
mobile/
  analysis_options.yaml
  lib/
    main.dart
  pubspec.yaml
  test/
    widget_test.dart
```

## Notes

The mobile app should consume the same Spring Boot REST API used by the web frontend.
